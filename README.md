## ✨ حول المشروع

**KATRO** مشروع يهدف إلى تقديم تجربة أنمي مميزة من خلال واجهة حديثة، وتصميم داكن، وسهولة في الاستخدام، مع هوية بصرية مستوحاة من عالم الأنمي.

## 🚀 مميزات الموقع

- 🎨 تصميم عصري واحترافي.
- 🌙 واجهة داكنة بتدرجات بنفسجية وزرقاء.
- 📱 متوافق مع الهواتف والأجهزة المختلفة.
- ⚡ واجهة سريعة وخفيفة.
- 🎌 هوية خاصة بعالم الأنمي.
- 🔗 قسم مخصص لتحميل التطبيق.

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- Responsive Design
